#To Run the 3 servers

1. Meter no diretorio C:\

2. Run the RunMazeServers.bat

3. in the cmd write:
> mongosh --port 23019

4. check if the the port you choose is the 'primary' one [ 23019, 25019, 27019 ]

5(optional). connect them in the MongoDBCompass
